# Text-Analytics-Project-Digital-Analytical-Addition
Text as Data Project ~ Digital Analytical Addition
Project on a Corpus of Film Scripts 
### Theme: Entrepreneurs
  - are there themes, or subgroups, to be uncovered via the screenplays of entrepreneurial films? Here, entrepreneurial films encompass plots that center around an individual or small group that reinvent a system or product on a large scale, typically with lasting impact. Specfically, retrospective films centered around a single antagonist.
  -  we will use Text Analytics, specifically Natural Language Processing via sentiment models, word embeddings, POS tags, etc. to investigate this theory
